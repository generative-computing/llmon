Span labeling

The task is to label spans of plain text with the class(es) that best describe them (Instruction, Constraint, Output Format, etc). Each entry in the loaded file gets its own page.

  • Highlight (select) a piece of text with your mouse, then pick a class from the popup to label it.
  • Click an existing highlighted span to relabel it, resize its boundaries, or delete it.
  • Spans can be nested inside each other, but shouldn't partially overlap — see the guidelines for what that means.
  • Mark an entry Complete once you're done with it so you can track progress in the sidebar, and use Undo/Redo (Ctrl/Cmd+Z) if you make a mistake.
  • See the Labeling Guidelines page (also linked in the sidebar) for the full class definitions and real examples.
There is no autosave. Everything lives only in this browser tab's memory. The only way to keep your work is clicking Export — closing the tab, refreshing the page, or navigating away without exporting will lose all progress.
